## 目录结构

```
personal-account-book/

├── models.py         # 数据模型
├── storage.py        # JSON 存储
├── add_record.py     # 新增记账

├── filter_records.py # 条件筛选
├── statistics.py    # 收支统计

└── screenshots/      # 演示截图
```

## 运行

```bash
python app.py
```
